# 💱 Currency Converter

A simple, fast, and user-friendly Currency Converter application that delivers accurate real-time currency conversions across global currencies.

## ✨ Features

- **Live Exchange Rates:** Fetches up-to-date conversion data via an exchange rate API.
- **Instant Calculation:** Converts amounts dynamically as you type or select currencies.
- **Quick Currency Swap:** Switch base and target currencies with a single click.
- **Clean & Responsive UI:** Fully accessible across mobile, tablet, and desktop screens.

## 🛠️ Built With

- **HTML5 & CSS3**
- **JavaScript (ES6+)** *(or React / Python)*
- **API:** [ExchangeRate-API](https://www.exchangerate-api.com/) *(or whatever API you used)*

## 🚀 Getting Started

### Prerequisites
Make sure you have Git installed. Clone the repository to get started:

\`\`\`bash
git clone https://github.com/your-username/currency-converter.git
cd currency-converter
\`\`\`

### Running Locally
- Open \`index.html\` directly in your browser, or serve it using VS Code Live Server.
